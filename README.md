# lbydzy

安全作业管理移动端交互原型。

固定访问地址：https://wang6122546.github.io/lbydzy/

包含6类待办、10类作业列表和申请表、作业详情、气体检测与本地记录。原生HTML/CSS/JavaScript，无需构建。

## 本地运行

```sh
python3 -m http.server 8766
```

浏览器访问 http://localhost:8766/ 。

## 数据与边界

数据为明确虚构的本地演示样例，操作仅保存在当前浏览器的 IndexedDB。不同访客不共享数据，不连接真实业务接口。
原站未能访问的后续评估、审批、验收和事件流程仍待确认；地图、人员及单位等选择采用本地模拟，不代表完整业务系统或全部页面已达到像素级1:1。
